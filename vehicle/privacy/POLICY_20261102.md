# 通用隐私来源观察规则

仅用于授权测试。规则来源是本文件（项目审计策略），API 定义来源在 catalog.py 中逐类记录。
独立于 VHAL rules.db；manifest 同时绑定本规则契约摘要与实际 Hook 摘要。

- VSC-GR-location / microphone / contacts / android_id：仅 outcome=ok 且返回值语义为 obtained
  时记录 observed。AudioRecord.read 必须返回正数；startRecording/start 仅调用，不算采集。
  联系人 query 仅登记游标，只有该游标实际 getString 返回非空值才记录取得数据。
- VSC-GE-android_id / contacts：同包、会话和可验证的同 UID/user，先读后发、30 秒内，
  完整 JSON 请求中某字符串叶子值的 SHA-256 前 16 位与读取值相同，才记录 correlated。
  contacts 至少 8 字符；不把数字行号、空值或同名字段当成值级证据。
  不使用响应、预览、形态标签或时间相近推断外发。
- 30 秒是工程基线，尚未做真实分布标定；相同值相关不证明唯一因果，更不自动判违法。
- 定位仅返回 Location 的观察，不由模拟坐标推断真实轨迹；当前不做定位/音频值级外发归因。
- 空值、错误、拒绝、未挂载、未覆盖及零观测分别展示；不产出 policy_violation。
- API 33/34/36 的通用来源有公开 SDK 依据，运行时逐方法检查；没有设备验收时标为未验证。
  不加载 API 35 的 VHAL 规则。车型、权限声明和 targetSdk 均不能代替设备 API 或实际返回值。
