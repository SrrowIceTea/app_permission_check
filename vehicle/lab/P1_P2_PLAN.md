# 本轮 P1/P2 工作范围

仅用于授权测试。目标是自有 AAOS 模拟器、隔离测试账号/服务和公开授权 APK；不操作量产车辆。

1. 运行真实 Home Assistant 服务，完成 Automotive App 登录、控制及传感器业务的可用路径。
2. 扩充到至少 3 个独立应用家族，核对官方 APK、安装身份、版本和实际完整业务步骤。
3. 记录独立服务端日志/动作回执/界面，形成 agent 初评；用户已选择保留人类签核项。
4. 校准读取—外发窗口：正例覆盖延迟批传，负例覆盖同值重复、窗口外/跨用户/仅时间相近。
5. 按真实样本差集补来源路径，推进 API34/33/36 的独立设备验收及车载生命周期场景。

每一阶段按实际结果写状态；下载、源码支持、模拟器通过、完整业务、人类标注分别计数。
模拟坐标、模拟行驶、睡眠/唤醒只代表模拟器；不冒充点火总线或真实驾驶状态。
不由 findings 自动生成 ground truth，不把 agent_reviewed 写为 independent_human_review。
失败运行保留；任何阻碍不能改为正常零发现。代码单文件 ≤300 行，完成后跑既有回归。
