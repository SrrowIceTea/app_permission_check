# 第三方链路收尾（下午续做）

## 1. 把「没数据」和「工具崩了」分开的三处修正
1. **conn_probe 读错了网络命名空间**：读 `/proc/net/tcp`（= adb shell 自己的 netns）在这台
   Android 16 上只有 2 行，应用一条都看不到，`adb root` 也没用（root 只改 uid 不改 netns）。
   必须读 `/proc/<pid>/net/tcp{,6}`，**tcp6 不能省**（应用外发几乎全在 tcp6，IPv4 走
   IPv4-mapped，前缀 `0000000000000000FFFF0000`）。改对后立刻看到真实连接。
2. **采样绑死 pid → 应用重启后整段失明**：本样本 150s 窗口内主进程 pid 从 10658 变 14037
   （应用自己崩溃重启）。改成 `--package` 模式，设备端每 `PIDOF_EVERY=25` 轮重解 pid
   （`set -- $(pidof pkg); PID=$1`，**只取第一个**，否则多进程时路径会拼成
   `/proc/1 2/net/tcp` 而静默读到零行）。pid 也从路径里取并进 dedup key。
3. **模拟器丢了默认路由**：`cmd wifi status` 报 "connected to"、wlan0 也 UP，但 `ip route`
   里**没有 default** → 应用一条都发不出去，而交付物上这和「应用没外发」长得一模一样。
   `ensure_wifi` 现在除 wifi 状态外**还验路由**，缺了就
   `ip route add default via 10.0.2.2 dev wlan0`（模拟器偏方，路由不会自己回来）。
   **教训：环境前提也要有判据，不能只看"看起来连上了"。**

# 规则库设计原理（2026-10-09 补齐调查）

## 三层分离架构（关键，答"规则库怎么设计的"必须讲清）
```
① 平台事实层  AOSP 源码抽取（可验证）：permissions / vhal_properties / dangerous_apis
② 项目策略层  POLICY.md（人写的判断，不是法律、不是平台定义）：P1 / R1 / E1
③ 规则 DSL 层 risk_rules = ①的 source_refs + ②的 basis_refs 拼接产物
```
- `seed_policy.py:8 draft_rules()` 是核心：**规则不从源码推导，而是把事实行"拼"上策略条款**。
  emit() 里 `source_refs = prop.source_refs_json + api.source_refs_json`、
  `basis_refs = POLICY.md + clause(P1/R1/E1) + sha256(POLICY.md)`。
  → 每条规则同时能答"依据哪个 AOSP 事实"和"依据哪条项目策略"。
- 种子规则 `enabled=0`（`notes`: "DISABLED draft. No evaluator implemented."），
  后由 EGRESS_CALIBRATION 实测校准后才启用。

4. **三方核对**：`verify_schema_parity.py`（schema 三方一致）；属性 ID/权限

## D307：绕过曾经是坏的——三处叠加的静默失败（答辩高价值案例）
现象：报告"已挂载"但一次都没触发，HTTPS 始终 `Trust anchor for certification path not found`。
1. **钩错类**：原代码 `tryUse(A) || tryUse(B)` 用 `||` 短路。`Java.use` 只要能**解析类引用**
   就返回非空，与类是否被加载/使用无关 → 钩子全挂在死类上（`org.conscrypt.*` 在设备上
   `enumerateLoadedClasses` 根本没有）。改为两个候选都钩 + 分别报告。
2. **异常类型匹配不全**：抛的是 `CertPathValidatorException`，而 `isBypassable` 只匹配

3. **返回空链**：`checkTrusted*` 返回空 ArrayList 会让 TLS 栈拿不到对端链而再次失败。

# 关键结论：不是所有 APK 都能 SSL 绕过 / 看明文（2026-10-09 实证）

## 一句话答案
**不能。** 只对「纯 Java + 标准 android.net 网络栈（conscrypt）」的 APK 有效；
native TLS / 手写指纹校验 / WebView 原生校验 / 非 Java 运行时（**Flutter、React Native**）
一律抓不到。且这**不是"暂时没做"，是当前架构的固有边界**。
