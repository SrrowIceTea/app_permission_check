01

不换皮，补一层。入口页的汽车摄影、细衬线标题和 204px 导航保留；问题集中在结果、进度、空态这些数据页。

01 / DIAGNOSIS

现状不是「不够现代」，是信息没有层级

以下每条都落到具体文件与行为。行号以当前仓库为准；问题按对复核效率的影响排序。

I-01

结论等级只有裸英文

results.js:86-87 · app.css:1258-1273

动态表第 3 列直接输出 observed / candidate。共享 CSS 里已有四色 .result-badge，但结果页从未使用。

不同等级没有形状差异，色弱用户与投影环境都无法一眼区分。

I-02

页面顶部没有汇总

results.js:89 · summary.json

findings_by_conclusion_level、代码定位缺口、采集校验状态都已经在后端摘要里，但要展开最后一个折叠块才能看到。

打开页面第一眼不知道「几条、几条待复核、几条证据不足」。

I-03

每行证据就是原始 JSON

results.js:30-35, 54-56 · vehicle.css:79-82

证据单元格 = details + JSON.stringify 全量。关键字段 event_ids / pairs / delta_ms / code_loc_gaps 没有结构；表格外层和 pre 各有一层滚动。

双层滚动、长包名撑行，复核只能逐行展开再肉眼找字段。

I-04

免责声明和告警同色

results.js:83 · app.css:1276-1294

「无观测不代表无风险」这类范围说明用黄色左线提示条；真正的「待复核」也用黄。两者在视觉上等价。

免责声明被当成告警，真正的风险提示被稀释。

I-05

进度只显示「已发生」

app.css:729 · app.js:11-20

5 个阶段全部有节点，但 .pl-pending 被隐藏；没有阶段耗时，也没有总耗时。运行中的长阶段看起来像卡死。

用户无法预期「还剩几步」，刷新后也只能从当前消息重新推断。

I-06

空态、未完成、失败三态同形

results.js:27-29, 77-79

U.empty() 一律塞一个 <p class="notice">。未选择任务、动态未完成、请求失败看起来一样，也没有下一步动作。

失败被当成空态，用户只剩「刷新」这一个动作。

I-07

连接状态没有视觉编码

vehicle.css:92 · app.js:147-161

.status-dot 被 display:none，断连只把文字改成「车载服务未连接」，颜色与正常态相同。

SSE 断开与正常运行在顶栏上不可区分。

I-08

上传校验发生在选文件之后

app.js:106-124 · app.html:112

模式、授权、后缀三项在 upload() 里逐条 return，错误落进 11px 等宽单行；授权勾选本身是 12px 小字。

用户先选文件再被打回，看不到「还差哪几项」。

02 / REFERENCES

同类产品实际怎么排证据

只列本轮真正看过的对象，以及准备借用 / 明确不照搬的部分。安全工具最容易犯的错是把「分数」当成「结论」，这里不做。

对象做法借鉴不照搬
MobSF移动安全审计按 high / warning / info 分级染色，每条 finding 带规则、描述、证据入口，报告按类别分组。四级语义 + 分组计数；每条结论都能追到规则与证据。0–100 安全分：容易被读成合规结论。

jadx-guiAPK 反编译左树、中码、搜索命中；选中上下文跨面板保持。源码页的选中态、搜索定位、返回原行。完整 IDE 外观与多标签。
Exodus Privacy权限与追踪器权限清单逐条标注 dangerous，tracker 按类别分组。权限 chip + 危险标记 + 分组标题。品牌 logo 墙，信息密度被图形吃掉。

03 / VISUAL

暗场入口 + 证据台，两套密度共用一套令牌

入口页继续用汽车摄影和低照度氛围；数据页去掉大光晕，改用细线、密排、语义色。深浅色不是两套设计，只是把同一组语义映射到两组底色。

暗色不是「把白底变黑」：正文用 #A8B7C2 而不是纯白；线用 12% 透明冷白；只有强调与状态色允许饱和。浅色把状态色压深到 AA 对比度，底色偏暖纸，避免医疗白。

四态必须同时有颜色、形状、文字

✓通过

采集校验、流程完整性通过。只描述流程，不等于「无风险」。

◐待复核

候选结论，需要人工或独立复核。黄色只留给它。

✕失败

任务失败、阶段未完成或校验未通过。必须带下一步动作。

▨证据不足

未观测、代码定位缺口、仅静态。斜纹 + 虚线，不能当安全。

另有结论级两态：●已观测 与 ◆已关联。同一青色系，用「描边 / 实心」表达强度，避免再加第五种色相。

层级与间距

elevation
三层停用阴影页底 / 面板 / 抬升面板只用底色差 + 1px 细线；数据页不加投影与光晕，避免表格漂浮。
rhythm
4 / 8 / 12 / 16 / 24 / 32 / 48区块 32，卡片内 16，行间 12，标签 8；不使用 20、28 这类无节奏值。
radius
3 / 6 / 10徽标 3，卡片 6，状态面板 10。表头、行、徽标之间保持同一圆角族。
04 / TYPOGRAPHY

中文正文用无衬线，衬线只留给固定标题

现有字体子集只覆盖界面常用词，动态证据里的生僻汉字会回退到系统无衬线——这可以接受，但必须让回退前后字号与行高一致，不能在同一句里跳字形再跳字号。

用途字体栈用法
标题"Noto Serif SC", "Songti SC", serif只用于页面大标题与固定品牌词；不与正文混排。
界面 / 正文"Manrope", "Noto Sans SC", "Microsoft YaHei UI", sans-serif拉丁与数字走 Manrope，中文走 Noto Sans；缺失字回退雅黑时不改字重。
标识 / 证据"Cascadia Code", Consolas, "Noto Sans SC", monospace规则 ID、包名、哈希、路径、原始 JSON；统一 tabular-nums。

字号阶梯

display 36 / 1.2
页面主标题只在「新建审计」「动态审计」等页首出现，一页一次。
title 17 / 1.4
结论标题比规则 ID 大，承担扫读入口；不再用 13px 全部压平。
body 14 / 1.75
说明与段落中文正文 14px，不超过 72 字符行宽。
data 13 / 1.65
表格与证据字段行高略紧，保证 8–12 行结论可一屏扫完。
label 11 / 1.4
表头、eyebrow、chip大写拉丁加 .12em 字距；中文不加字距。
mono 12 / 1.7
ID / 哈希 / JSON比正文小 1px，靠等宽对齐而不是加粗。

长路径与哈希

规则 ID 按连字符断行即可（overflow-wrap:anywhere 只在没有连字符时兜底）；SHA-256 与 base64 必须整段断行、禁止省略号；路径优先保留头尾，中段省略需要 JS，不放进「纯 CSS」清单。

/* 可断行，不截断 */
.hash, .path, .rule-id { font-family: var(--font-mono); font-variant-numeric: tabular-nums;
  overflow-wrap: anywhere; word-break: break-word; }
/* 只给哈希：每 8 字符留一个可读断点（JS 插入 <wbr>，CSS 不猜） */
.copy { min-width: 28px; height: 28px; }

密度取舍

只保留一档「舒适」密度：行高 44px、单元格 12px 16px、表头 sticky。结论用卡片列表而不是宽表，把横向空间还给证据链；需要对比多列（静态 8 列）时才退回表格。展开的证据抽屉限高 360px 内部滚动，页面本身不再出现第二根横向滚动条。

05 / INTERACTION

把「等待」和「失败」做成可读状态

交互改动优先做五件事：上传前校验清单、进度时间线、任务恢复、三态组件、可复制字段。全部可在现有 SSE 与 REST 字段上先做降级版。

1 · 上传：先校验，再上传

选中文件立刻显示文件卡（名称、大小、SHA-256 占位），下方三项校验用同一套四态中的「通过 / 待补 / 失败」：.apk 后缀、授权已勾选、当前无运行中任务。未勾选授权时点上传，不弹错，直接把焦点移到复选框并展开说明。

2 · 进度：五段全部可见，带耗时

静态规则0:12
反编译1:04

校验关联等待

图 1 待执行阶段保持可见（虚线），当前阶段展开一行消息，已完成阶段折成耗时。失败时该段变红并展开 next_action。

耗时直接由 SSE 事件的 ts 差计算，不改后端；总耗时显示「已运行」，完成后再显示终值，不预估 ETA。刷新后先渲染快照里的终态，再补事件，避免闪回。

4 · 任务切换与恢复

保留现有原生 select，但把选项改成「名称 · 状态 · 编号尾 4 位」，历史按钮不再显示裸 ID。页面记住最后查看的任务（localStorage 只存 job id），刷新优先恢复它；任务仍在跑时自动重连同一 SSE，已结束则直接取摘要与结论。

5 · 三态、键盘与复制

空态、加载态、错误态各用一个组件：图标 + 一句话原因 + 一个主操作 + 一个次操作。错误态必须写清是「服务未连接 / 任务失败 / 数据缺失」哪一种，不用「加载失败」一锅端。

键盘：首屏加「跳到主内容」skip link；导航加 aria-current；进度容器 aria-live="polite" 只播报阶段变化；:focus-visible 统一 2px 青色环，不用浏览器默认虚线；details summary 保留原生可聚焦。复制按钮覆盖：规则 ID、会话 ID、包名、SHA-256、文件路径、证据 JSON。

07 / ACCEPTANCE

验收看这几条，不看「感觉变好看了」

可在无设备环境完成；涉及真实任务的用本机历史产物，不重跑采集。

  • 1280 / 1440 / 1920 三档无横向滚动，表头 sticky 不遮首行。
  • 四态在灰度截图下仍可区分（形状/文字，不只颜色）。
  • 深浅色正文对比度 ≥ 4.5:1，状态徽标 ≥ 3:1。
  • 200% 缩放下结论卡片不重叠，长哈希不撑破容器。
  • Tab 顺序：导航 → 主内容 → 任务选择 → 结论列表 → 抽屉。
  • 进度刷新后不闪回，失败段能展开 next_action。
  • 复制按钮在 http://127.0.0.1 下全部可用（file:// 不作为验收环境）。
  • 零构建：不新增 npm/打包步骤，python -m http.server 可直接打开。
