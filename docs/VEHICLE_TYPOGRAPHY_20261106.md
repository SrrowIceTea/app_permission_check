# 车载字体与艺术排版

用户反馈：顶部当前样本和历史下拉的字体生硬，希望页面有艺术排版。

改动：

- 中文标题改用细笔画 Noto Serif SC，品牌与英文采用 Manrope，普通中文界面使用 Noto Sans SC。
- 顶部去除等宽和过大的字距，APK 文件名只显示一份，完整名称保留在悬停提示中。
- 历史选择改为紧凑控件，内部仍是带无障碍标签的原生 select，不破坏键盘或读屏操作。
- 统一导航、按钮、说明、进度和结果卡的字号层次，代码与原始证据仍保留等宽字体。
- 本地保存三个字体文件（共 124,652 字节）及完整 OFL 许可，不在页面运行时请求外部字体服务。
- 服务器只增加两个样式文件及三个字体文件的精确白名单路由。

视觉延续现有汽车摄影，左侧细衬线标题作为主视觉，操作与数据文字保持清楚的无衬线层次。
没有变更规则、采集、审计、AI 行为或移动端前端。

字体来源、子集与许可见 [字体说明](../vehicle/frontend/assets/fonts/README.md)。
