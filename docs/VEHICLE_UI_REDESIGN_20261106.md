# 车载审计页排版与汽车背景

仅用于授权测试（自有设备与自有 APK）。

用户反馈：完成卡片遮住授权文字、标题与结果位置失衡，希望加入汽车背景。

根因是共享移动端 CSS 的完成态 `margin-top: calc(-1 * var(--slot-h))`：
移动舞台使用覆盖过渡，移植后的车载表单和正常流布局仍继承该规则。
另有手机上传框与结果卡各自的 `margin: 0 20px`，使内容左右错位。

本轮修正：

- 车载标题、结果与进度恢复正常文档流，完成卡不再上移覆盖。
- 标题和操作区左对齐；设置只在新建态展示，运行与完成态隐藏。
- 完成态保留可见进度；新建恢复设置、上传区和授权确认。
- 上传框、结果卡与标题在三种屏宽下保持同一左边界。
- 使用 ImageGen 生成无品牌汽车棚拍背景，右侧展示车辆，左侧保留可读操作区。
- 图片保存为 `vehicle/frontend/assets/vehicle-studio.png`，只开放该固定本地资源路径。
- 移动端 `frontend/`、规则、采集与审计实现未修改。
